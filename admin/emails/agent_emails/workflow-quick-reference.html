🔄 Email Workflow Quick Reference

Everything you need to know about automated email follow-ups

🚀 Getting Started (3 Steps)

Step 1: Go to Sales Portal → Email Workflows
Step 2: Create a workflow template (e.g., "Unopened - 3 Day Reminder")
Step 3: When sending emails, select your workflow from dropdown
💡 That's it! The system automatically sends follow-ups based on how recipients interact with your email.

📋 Workflow Trigger Types

Unopened

When: Recipient hasn't opened the email
Best For: Gentle reminders
Recommended Delay: 72 hours (3 days)

Opened but Not Clicked

When: Email was read but no links clicked
Best For: Providing more info, answering questions
Recommended Delay: 120 hours (5 days)

Clicked but No Action

When: Clicked links but took no action on website
Best For: Urgent follow-up, offering help
Recommended Delay: 48 hours (2 days)

Clicked but No Sale

When: Browsed products but didn't buy
Best For: Addressing concerns, offering incentives
Recommended Delay: 72 hours (3 days)

Sale with Agent Follow-up

When: Customer made a purchase
Best For: Thank you, relationship building
Recommended Delay: 24 hours (1 day)

AI Chat Interaction

When: Used AI assistant after clicking email
Best For: Warm lead personal follow-up
Recommended Delay: 48 hours (2 days)

✨ Three Ways to Use Workflows

1. Transactional Campaign (One Email)

  • Send important email with workflow attached
  • Workflow triggers ONLY for that specific email
  • Perfect for: proposals, demos, important announcements

2. Reusable Template (Multiple Emails)

  • Create workflow template once
  • Attach to any email you send
  • Perfect for: common scenarios, consistent follow-up strategy

3. Entity-Specific (All Emails to Lead/Account)

  • Configure workflows for specific lead/account
  • Applies to ALL future emails to that contact
  • Perfect for: VIP clients, high-value leads, custom timing needs

🎯 Best Practices

DO:

  • ✅ Use AI generation for personalized follow-ups
  • ✅ Start with 3-day delays for unopened emails
  • ✅ Monitor performance and adjust
  • ✅ Use different workflows for different lead types
  • ✅ Cancel workflows if you follow up manually

DON'T:

  • ❌ Create too many follow-ups (max 3 per email)
  • ❌ Use aggressive delays (< 24 hours for unopened)
  • ❌ Forget to monitor your active campaigns
  • ❌ Leave workflows running if you're handling manually

📊 Tracking Performance

Go to Email Workflows → Performance to see:

  • How many follow-ups have been sent
  • Open rates per workflow
  • Conversion rates
  • Which workflows work best

🎓 Example Scenarios

Scenario: Cold Lead Follow-up

  1. Send introduction email to cold lead
  2. Attach "Unopened - 3 Day" workflow
  3. If not opened → AI sends friendly reminder after 3 days
  4. If opened but not clicked → Different workflow triggers after 5 days
  5. Fully automated nurturing!

Scenario: Post-Demo Follow-up

  1. Send demo recap email
  2. Attach "Clicked but No Sale" workflow
  3. If they browse products → Follow-up offering assistance
  4. If they purchase → Thank you email sent automatically
  5. Smart automation based on their interest level!

Scenario: VIP Client Management

  1. Go to account detail page
  2. Click "Configure Follow-up Workflows"
  3. Set custom 12-hour delay for unopened
  4. Enable time optimization for 10 AM sends
  5. All emails to this client now follow VIP timing!

❓ Common Questions

Q: Can I cancel a scheduled follow-up?

Yes! Go to Active Campaigns tab and click Cancel on any pending follow-up.

Q: What happens if I manually follow up?

You should cancel the automated follow-up to avoid duplicate contact. Better yet, the system is smart - if the lead replies or converts, some workflows auto-cancel.

Q: Can I see what the follow-up will say?

If using AI generation, the content is generated dynamically based on recipient behavior. If using a template, you can preview it in Email Automation.

Q: How many follow-ups will be sent?

Maximum 3 per original email (configurable). Each follow-up can trigger its own workflow if needed.

Q: Can I customize timing per client?

Yes! Use the "Configure Follow-up Workflows" button on any lead/account to set custom delays and send times.
