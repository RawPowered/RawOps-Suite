# RawOps Suite v1.0.0-showcase

A preserved source release showing how CRM, sales education, assisted outreach, sample fulfillment, finance and legal operations were connected in one business platform.

## Explore

- Product-aware training, quizzes, progress and sales practice.
- Geographic shop discovery, CRM records and contextual email drafting.
- Catalog-aware chat assistance and follow-up workflows.
- Free samples, fulfillment handoffs and customer accounts.
- Agent digital cards, vCards, QR generation and referral context.
- Legal timelines, evidence metadata, access requests and session tracking.
- Inventory, production, commissions, accounting and operational reporting.

## Included

Scrubbed application source, 122 API source files, 145 migration files, 11 historical captures, workflow diagrams, implementation notes and a recruiter-oriented walkthrough. The README uses RawPowered's charcoal, angled-panel and lime-accent visual style.

## Validation and scope

437 PHP files and 33 standalone JavaScript files passed syntax inspection. Gitleaks 8.30.1 reported no secrets in the release tree. Local documentation links and the added graphics were checked.

This is a historical source and showcase release. Runtime configuration and private data are excluded; deployment and external integrations have not been revalidated. Read [publication review](docs/PUBLICATION-REVIEW.md) and [source review](docs/SOURCE-REVIEW.md) for the boundaries and restoration requirements.
